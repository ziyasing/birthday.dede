KARTU ULANG TAHUN IYASH — 8 TAHUN

Cara membuka:
1. Extract ZIP ini.
2. Buka file index.html di Chrome/Edge.
3. Semua foto sudah ada di folder assets.

MUSIK:
Website sudah punya playlist. Untuk menambahkan lagu:
1. Buat folder bernama "music" di samping index.html.
2. Masukkan file MP3 dan beri nama:
   - song1.mp3
   - song2.mp3
   - song3.mp3
3. Buka ulang index.html.
Catatan: audio tidak disertakan agar website tidak mendistribusikan musik berhak cipta tanpa file yang kamu miliki.
